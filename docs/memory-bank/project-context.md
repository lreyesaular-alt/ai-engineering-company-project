# Contexto del proyecto

## Aplicación

Talent Pipeline Tracker es una aplicación interna para gestionar candidaturas. El proyecto está en `uis/talent-pipeline-tracker/` y su README documenta el trabajo del Hito 3.

La aplicación permite trabajar con candidaturas mediante listado, búsqueda, filtros, creación, edición, cambios de estado y gestión de notas.

## Alcance separado

El `CONTEXT.md` de la raíz describe Brasaland, una cadena de restaurantes, y los requisitos del Hito 1 para un sitio web público y el programa Brasa Points. Ese contexto no describe el dominio funcional del Talent Pipeline Tracker.

Para cambios en el tracker, el alcance funcional verificable debe tomarse del README del tracker y de su código actual.

## Requisitos funcionales documentados para el Hito 3

El README del tracker registra estos objetivos: dashboard en Next.js, integración con la API real, lista de candidatos, filtros de estado, búsqueda, panel de detalle, notas, estados robustos de carga y error, creación mediante `POST /records`, paginación, edición, cambio de estado, eliminación de notas y búsqueda global.
