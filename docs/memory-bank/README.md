# Memory Bank

Memoria mínima para futuros agentes que trabajen en Talent Pipeline Tracker.

## Orden de consulta

1. `api-contract.md`: endpoints, respuestas y estados observados en el código.
2. `architecture.md`: estructura técnica y responsabilidades de los módulos.
3. `current-state.md`: capacidades implementadas y comportamiento actual.
4. `working-rules.md`: reglas operativas verificables en el proyecto.
5. `project-context.md`: alcance funcional y separación respecto al contexto corporativo raíz.

## Fuentes y alcance

Esta memoria se basa únicamente en `CONTEXT.md`, `README.md`, `uis/talent-pipeline-tracker/README.md`, `uis/talent-pipeline-tracker/AGENTS.md` y el código actual del tracker.

`CONTEXT.md` describe Brasaland y el Hito 1 del sitio web público. El tracker es una aplicación de selección de talento documentada en su propio README y código; no deben mezclarse ambos alcances.

No guardar aquí secretos, credenciales ni datos reales de candidatos. Actualizar los documentos cuando cambien el código o los contratos comprobados.
